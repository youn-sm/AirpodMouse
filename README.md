# AirpodMouse — 에어팟 마우스

**한국어** | [English](README.en.md)

헤드 트래킹을 지원하는 에어팟(AirPods Pro · AirPods 3세대 이후 · AirPods Max)의 모션 센서로 커서를 움직이고,
단축키 · 에어팟 기둥 누르기 · 머무르면 클릭으로 클릭하는 macOS 메뉴바 앱.

[PodMouse](https://github.com/tony1010-dev/PodMouse)(MIT)를 바탕으로, 마우스 기능만 남기고 커서 움직임과 클릭을 다듬은 포크예요.

## PodMouse와 다른 점

- **마우스만**: 음성 입력, 머리 제스처, 조이스틱/절대 이동 모드를 뺐어요.
- **더 매끄러운 커서**: One Euro 필터로 떨림을 거르고, 속도에 따른 S자 가속 곡선, 고개가 멈추면 커서를 고정하는 멈춤 기준(드리프트 흡수),
  25Hz 센서 값을 화면 주사율에 맞춰 고르게 나눠 움직여요.
- **머무르면 클릭**: 커서를 잠깐 멈추면 링이 차오르고 클릭돼요. 손을 전혀 안 쓸 때 좋아요. ⌃⌥W 또는 기둥 3번으로 켜고 꺼요.

## 요구 사항

- macOS 14 (Sonoma) 이상, Apple 실리콘 Mac 권장
- 헤드 트래킹을 지원하는 AirPods (이 Mac에 연결된 채로 착용)
- Xcode 또는 Command Line Tools (`swiftc`)

## 설치 · 빌드

```bash
./install.sh            # 빌드 → /Applications/AirpodMouse.app 설치 → 실행
./build.sh              # build/AirpodMouse.app 만 만들기
./test.sh               # 커서 계산 로직 테스트
./install.sh uninstall  # 삭제
```

개발자 인증서가 있으면 자동으로 그걸로 서명해요. 없으면 ad-hoc 서명이라 다시 빌드할 때마다 손쉬운 사용 권한을 다시 켜야 할 수 있어요.

처음 실행 시 허용할 권한: **손쉬운 사용**(커서 이동·클릭), **동작 및 피트니스**(에어팟을 끼면 물어봄).

## 조작법

| 입력 | 동작 |
|---|---|
| 고개 좌우로 돌리기 / 들기 · 숙이기 | 커서 이동 (천천히 = 정밀, 빠르게 = 멀리) |
| ⌃⌥ , | 왼쪽 클릭 · 두 번 = 더블클릭 · 꾹 누르고 고개 움직이기 = 드래그 |
| ⌃⌥ . | 오른쪽 클릭 |
| 에어팟 기둥 1번 / 2번 / 3번 | 왼쪽 클릭 / 오른쪽 클릭 / 머무르면 클릭 켜기·끄기 |
| 커서를 멈추고 기다리기 | 머무르면 클릭 (켜져 있을 때) |

| 단축키 | 기능 |
|---|---|
| ⌃⌥M | 마우스 모드 켜기/끄기 |
| ⌃⌥W | 머무르면 클릭 켜기/끄기 |
| ⌃⌥R | 기준 재설정 + 커서 화면 중앙 |
| ⌃⌥D | 드래그 고정 시작/끝 |
| ⌃⌥S | 스크롤 모드 |
| ⌃⌥= / ⌃⌥- | 감도 올리기/내리기 |

- 기둥 누르기는 **마우스 모드가 켜져 있을 때만** 클릭으로 바뀌어요. 꺼지면 음악 재생/정지로 돌아가요.
- 1번 누르기는 에어팟이 2번 누르기인지 기다렸다 신호를 보내서 약 0.3~0.5초 늦게 클릭돼요.

## 보정 팁

- 설정 탭 → **실시간 센서**에서 값이 움직이는지 먼저 확인하세요.
- 커서가 서서히 흐르면 **멈춤 기준**을 올리세요 (가만히 있을 때의 '걸러진 속도'보다 높게).
- 클릭하려고 멈출 때 흔들리면 **떨림 거르기**를 올리세요.

## 한계

- 헤드 트래킹 데이터는 Apple의 `CMHeadphoneMotionManager`로 받아서 약 25Hz이고, 좌우(yaw)는 절대 기준이 없어 조금씩 흘러요.
- 에어팟이 귀에 있고 이 Mac에 연결돼 있어야 값이 나와요. 충전 케이스 안에서는 값이 오지 않아요.
